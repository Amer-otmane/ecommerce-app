## 📌 Description

Application web e-commerce complète permettant la gestion 
des produits, clients et commandes avec authentification JWT.

---

## 🛠️ Technologies utilisées

### Frontend
- Angular 21
- TypeScript
- HTML / CSS

### Backend
- Node.js + Express
- JWT (authentification)
- MySQL

---

## ⚙️ Installation

### 1. Cloner le projet
```bash
git clone https://github.com/Amer-otmane/ecommerce-app.git
```

### 2. Lancer le Frontend
```bash
cd ecommerce-app
npm install
ng serve
```

### 3. Lancer le Backend
```bash
cd ecommerce-backend
npm install
node server.js
```
